⚡ Flash Share – Fast File Transfer

Developed by @Monirhossain746

Flash Share is a modern, lightweight, and high-speed file-sharing application designed to transfer files seamlessly between Android devices and Windows PCs using local Wi-Fi and mobile hotspot connections.

Share your photos, videos, documents, APKs, ZIP archives, ISO images, and other file formats without requiring an internet connection.

🚀 Key Features

- ⚡ High-Speed Offline File Transfer
- 📱 Phone-to-Phone File Sharing
- 💻 Phone-to-PC File Transfer
- 🔄 PC-to-Phone File Transfer
- 🌐 Local IP Address-Based Connection
- 📡 Wi-Fi and Mobile Hotspot Support
- 📶 2.4GHz and 5GHz Network Compatibility
- 📂 Support for Multiple File Formats
- 📦 Large File Transfer Support
- 🎨 Modern and Professional UI
- 🔒 Secure Local Network Communication
- 🚀 Lightweight and Performance-Optimized Design

📁 Supported File Types

Images, Videos, Audio, Documents, APK, ZIP, RAR, 7Z, ISO, EXE, MSI, and many more.
